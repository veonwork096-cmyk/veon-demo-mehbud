# Мехбуд — сайт (VEON)

Код главной страницы и материалы дизайна для дальнейшей разработки сайта Мехбуд.
Исследования, клиентские PDF и данные о компании хранятся в папке проекта у сотрудника и в этот репозиторий не входят.

## Структура
- `site/` — код сайта (Astro): главная страница по утверждённой концепции.
- `design/concept.md` — концепция редизайна: структура главной, палитра, шрифты, анимации, что показано сейчас и что после согласования.
- `content/` — тексты сайта (если есть).

## Локальный запуск (macOS и Windows, Node.js 18.20.8+)
```bash
cd site
npm install
npm run dev        # разработка, адрес из вывода (обычно http://localhost:4321)
npm run build      # сборка в site/dist
npm run preview    # просмотр собранной версии
```

## Публикация
Сборка — статические файлы в `site/dist` (команда `npm run build`, папка публикации `site/dist`), их можно разместить на любой платформе статического хостинга без изменения кода.
